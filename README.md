# Fawwaz Ahmed Portfolio

This is my personal portfolio website showcasing my projects, technical skills, and experience in software development and cybersecurity.

## Features

- Modern and responsive UI built with TailwindCSS
- Light/Dark Mode
- Tech Stack visualization
- Project showcase section
- Blog support (MDX & Markdown)
- Visitor counter and analytics integration
- SEO optimized

## Tech Stack

- Next.js 16 + React 19
- TailwindCSS
- TypeScript
- Shadcn/UI
- AWS

## Demo

## Configuration

- `.env.local` - environment variables
- `src/config/siteConfig.ts` - site configuration
- `src/config/infoConfig.ts` - personal information
- `src/config/*.ts` - section configurations
- `src/content/blog/**.mdx` - blog content
